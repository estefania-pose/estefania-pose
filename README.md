# Hola, soy Estefanía Pose 👋

Especialista en Testing de Software (QA) y Analista de Datos con una mentalidad nativa de precisión, rigor y mitigación de riesgos. Me apasiona el análisis lógico y el control de calidad. Mi experiencia previa coordinando equipos y gestionando situaciones críticas bajo presión me dio una espalda única para adaptarme a metodologías ágiles, documentar procesos meticulosamente y resolver problemas complejos en equipo.
